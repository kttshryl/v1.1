#  Вселенная и наш дом

Учебный проект из двух страниц: этапы развития Вселенной и Солнце с планетами. Две версии в Git (v1.0 и v1.1).

## Запуск
Откройте `index.html` в браузере 
## Файлы
- `index.html` — этапы развития Вселенной
- `about.html` — Солнце и 8 планет
- `style.css` — стили v1.0
- `style2.css` — стили v1.1
- `PLAN.md` — план обновления
- `screenshots/` — скриншоты страниц

## Версии
- **v1.0** — базовая тёмная тема, две страницы, сетка планет.
- **v1.1** — градиенты, hover-анимации, sticky-навигация, шрифты Google Fonts, свечение.

Переключение: `git checkout v1.0` / `git checkout v1.1`
